# 300档优化版发布说明

发布目录仅保留 `release/speed300`，默认入口为根目录 `烧录.ps1`。

## 实现

保留原触摸选择与外观跟踪，PS缩图从4×4全部16点均值改为中央4点均值。
帧大小仍是800×480×4字节；没有PL裁剪、PL缩图或DMA压缩。
增加128样本请求到识别、请求到DMA完成、DMA完成到识别完成的分位耗时。
后者含协作调度等待，不是CPU独占耗时。

两轴300μs/s，Kp=2、Ki=Kd=0，加速度800、减速度1200μs/s²，死区15/22。
默认下载后手动、PWM关闭。参数恢复默认500～2500μs宽范围实验限幅；
加 `-EnableAuto` 后启用跟随，点击目标后开始调整。

## 验证

2026-11-03实板反馈：“绿框稳定，跟随与停稳正常”。
随后128样本统计P50=49105μs、P95=49200μs，DMA段P50=30556μs，
DMA完成到算法完成P50=17191μs。没有同场景原300档对照，不报告加速比例。
后续采样瞬间处于LOST并保持，目标是否仍在场没有确认；不把该瞬间当作误丢失或完整失目标验收。

- 外观78241项，运行时391项，轨迹1910项，尺寸稳定809项通过。
- 裸机17个C文件重新编译通过，_end=0x00300c90，低于帧缓存0x01100000。
- 发布ELF重新编译自本仓库源码，代码、常量、数据及向量段与实板程序逐字节一致。
- BIT/XSA/BSP复用相同的触摸硬件；没有新增RTL，没有重新宣称布局布线结果。
- 该硬件既有报告WNS +0.571ns、WHS +0.014ns；外部接口约束覆盖范围按原报告解释。

详细日志和对比结果位于 `docs/evidence/speed300/`。
历史记录保留在其他证据目录及Git历史，不代表本版重复完成过所有历史验收。

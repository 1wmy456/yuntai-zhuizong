# 接线与运行

|功能|引脚|连接|
|---|---|---|
|水平PWM|U5，J4-3|水平MG90S信号|
|俯仰PWM|T5，J4-4|俯仰MG90S信号|
|公共地|J4-37或J4-39|舵机地、外部5V电源地|
|舵机电源|外部5V|两舵机电源端|
|触摸SCL/SDA|R19/P20|LCD触摸接口|
|触摸RST/INT|M19/U19|LCD触摸接口|

LCD为800×480，ID 0x4384，触摸为GT1158、I²C地址0x14。摄像头和LCD通过原配排线连接，新增PWM及触摸约束在constraints目录。

串口115200、8N1、ASCII命令加CR/LF。一次只允许一个程序占用串口。JTAG下载与脚本恢复参数通过XSCT完成，不要求关闭未占用JTAG的串口接收界面。

点击目标后观察TRACK和绿框。SELECT等待选择，LOST清框并保持。目标切换不回中；点击空白且初始化失败时保留有效模型。关闭自动用manual，关闭脉冲用disable。
